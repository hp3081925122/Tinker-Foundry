# Tinker Foundry 方块交互 / UI / 客户端功能测试文档

适用版本：1.20.1 Forge（`1201forge`）、1.21.1 NeoForge（`master`）、26.1.2 NeoForge（`2612neoforge`）。三版测试项相同，版本差异在每节末尾单独标注。

## 0. 准备

1. 新建创造模式超平坦测试世界，允许作弊；建议同时安装 JEI。
2. 调试命令需要 OP 2 级，全部位于 `/tinker_foundry debug` 下：

| 命令 | 作用 |
|---|---|
| `generate smeltery` | 在面前 8 格生成 5×5×3 冶炼炉：控制器、燃料罐（8000 mB 熔岩）、排液口、浇注口、铸造盆、浇注台，炉内预装 1000 mB 熔融铁 |
| `generate foundry` | 同上，焦黑版熔铸炉 |
| `generate alloyer` | 合金炉 + 下方焦黑燃料罐（8000 mB 熔岩）+ 两侧锭罐（熔融铁、熔融金各 1000 mB） |
| `generate all` | 一次生成以上三套，左右相隔 10 格 |
| `fill <数量> <流体ID>` | 向准星 8 格内的冶炼设备注入流体，流体 ID 有补全 |
| `potion <数量> <药水ID>` | 向准星设备注入带药水数据的药水流体 |
| `drain` | 抽空准星设备（最多抽 64 次） |
| `kit` | 发放测试物品包：铸模、铜罐、砖、焦黑砂浆、玻璃瓶、碗、桶、圆石/石头类、矿石、锭、宝石、玻璃、灵魂沙、煤、黏土、铁剑、铁胸甲 |

3. 日志关键字：`[debug-command]`。命令失败时会在聊天栏给出中文原因。
4. 每个测试项记录：版本、结果（通过/失败）、截图或日志行。

## 1. 方块交互测试

### 1.1 冶炼炉 / 熔铸炉结构

| # | 操作 | 预期 |
|---|---|---|
| 1.1.1 | `generate smeltery`，右键控制器 | 打开冶炼炉界面，提示「结构有效」，显示燃料和 1000 mB 熔融铁 |
| 1.1.2 | 拆掉一块侧墙后再右键 | 显示「结构无效」，熔炼停止；补回方块后恢复有效 |
| 1.1.3 | 在炉腔内放一个方块 | 结构无效（炉腔必须是空气） |
| 1.1.4 | 把燃料罐挖掉 | 界面燃料栏提示「结构内缺少储罐」；燃料罐掉落物保留流体（物品提示可见），放回后流体还在 |
| 1.1.5 | 扩大炉腔（加高一层） | 输入槽数量增加，原物品和热量保留；旧界面被关闭，需重新打开 |
| 1.1.6 | 缩小炉腔 | 超出的输入物品掉在控制器附近，不会消失 |
| 1.1.7 | 用焦黑方块混入冶炼炉外壳 | 结构无效（材质不能混用） |
| 1.1.8 | `generate foundry` 重复 1.1.1～1.1.6 | 结果相同，标题为「熔铸炉」 |

### 1.2 熔炼

| # | 操作 | 预期 |
|---|---|---|
| 1.2.1 | 往输入槽放铁锭、金锭、铜锭 | 升温后熔化，分别生成熔融铁/金/铜层 |
| 1.2.2 | 放入圆石 | 熔成焦黑石流体（seared stone） |
| 1.2.3 | 放入铁剑、铁胸甲 | 按配方熔出熔融铁 |
| 1.2.4 | 放入无配方物品（泥土） | 槽位提示「该物品无法被熔炼」 |
| 1.2.5 | `drain` 抽空燃料罐后放铁锭 | 提示燃料不足/温度不足，不熔化；`fill 8000 minecraft:lava` 后恢复 |
| 1.2.6 | 炉内流体加到接近满再放金块 | 提示「剩余空间无法容纳产出的流体」，物品不消失 |
| 1.2.7 | 在冶炼炉内同时有熔融铜和其他合金材料 | 有合金配方时冶炼炉自动合金；熔铸炉不自动合金 |
| 1.2.8 | 让僵尸、蜘蛛等生物走进炉腔（熔岩燃料下） | 生物受伤并产出对应流体（僵尸→熔融铁 10 mB 等）；蜜蜂→蜂蜜，史莱姆→史莱姆流体 |

### 1.4 浇注口 / 浇注台 / 铸造盆（重点：本次修改）

先 `kit` 拿到铸模，`generate smeltery`。

| # | 操作 | 预期 |
|---|---|---|
| 1.4.1 | 空手右键浇注口 | 浇注口开始出流体（炉内底层），流向下方铸造盆 |
| 1.4.2 | 浇注台放入锭铸模，浇注口对准浇注台，炉内熔融铁 | 铸出铁锭，铸模保留 |
| 1.4.3 | 浇注台放金粒铸模 + 熔融金 | 铸出金粒 |
| 1.4.4 | 铸造盆不放东西 + 熔融铁 810 mB 以上 | 铸出铁块 |
| 1.4.5 | 铸造盆放 1 个铜块以外的物品（如圆石） | 盆只接受 1 个物品；圆石 + 焦黑石流体 → 焦黑圆石（basin 配方） |
| 1.4.6 | 浇注台放圆石 + 焦黑石流体 | **不应**生成焦黑圆石（该配方只在盆里） |
| 1.4.7 | 盆中放焦黑圆石台阶/楼梯/墙，用焦黑石流体 | 分别得到对应焦黑物品 |
| 1.4.8 | 结果完成后空手右键台/盆 | 取出成品；模具可取回 |
| 1.4.9 | 浇注口改用 `seared_casting_tank` 接收 | 能装填/倒空物品内储罐 |

### 1.5 熔炼器 / 加热器 / 合金炉

| # | 操作 | 预期 |

| 1.5.2 | 熔炼器放在加热器上，加热器放煤 | 固体燃料供热，界面燃料显示「固体燃料」 |

| 1.5.5 | 挖掉合金炉下方燃料罐 | 提示「合金炉下方缺少燃料罐或加热器」 |
| 1.5.6 | 合金生产 | **本体没有自带合金配方**（三版 `alloying` 目录都为空），需用下面的测试数据包验证 |

测试合金数据包（1.21.1，放 `data/test/recipe/alloying/test.json`；1.20.1 目录为 `recipes`，26.1.2 的 `ingredient` 直接写流体 ID 字符串）：

```json
{
  "type": "tinker_foundry:alloying",
  "ingredients": [
    {"ingredient": {"fluid": "tinker_foundry:molten/iron"}, "amount": 10},
    {"ingredient": {"fluid": "tinker_foundry:molten/gold"}, "amount": 10}
  ],
  "result": {"id": "minecraft:lava", "amount": 20},
  "temperature": 800
}
```

预期：`/reload` 后合金炉消耗两侧熔融铁、金，产出熔岩。
