# 26.1.2 GameTest 逐项移植记录

核对范围：`1.20.1-forge-tinker-foundry` 与 `Tinker Foundry` 的 `FoundryGameTests`，目标为 `26.1.2-neoforge-tinker-foundry`。

## 移植原则

- 保留两个前置版本的 20 个测试方法及其断言、延迟回调、结构布置和存档检查。
- 只替换 NeoForge 26.1.2 必需的注册入口、方块实体读取、能力查询和存档 API。
- 不把多个测试合并到一个烟雾测试，也不通过删除断言来规避版本差异。
- 配方 Codec 测试使用 26.1.2 当前 `FluidIngredient.CODEC` 所要求的流体标识字符串格式。

## 26.1.2 API 对照

- 使用 `RegisterEvent` 注册 20 个独立测试函数，再通过 `RegisterGameTestsEvent` 注册 20 个独立测试实例。
- 使用 `GameTestHelper.getBlockEntity(pos, FoundryBlockEntity.class)` 完成类型读取。
- 使用 `FoundryCapabilityCompat.internalFluid` 检查浇注口内部流体能力。
- 使用带 `registryAccess()` 的 `saveWithFullMetadata` 与 `BlockEntity.loadStatic` 验证存档。
- 使用 26.1.2 的 `FluidIngredient` 流体标识格式解析合金配方 JSON。

## 验证结果

执行 `compileJava` 后运行 `runGameTestServer`。测试服务器共执行 21 项：20 项移植测试加 1 项原版默认测试；结果为 **21/21 required tests passed**。
